
# 🌐 Personal Portfolio Website

A modern, responsive, and interactive personal portfolio website built using **React.js, Vite, JavaScript, HTML, and CSS** to showcase my technical skills, academic background, projects, certifications, and professional experience.

The portfolio reflects my journey as an undergraduate specializing in **Data Science**, with a strong interest in **Software Engineering, Artificial Intelligence, Machine Learning, and Data Analytics**.

## 🚀 Live Website

🌐 **Portfolio:** [Visit My Portfolio](https://ruwinya-karunarathna-portfolio.vercel.app/)

## ✨ Features

- 🏠 **Home Section** – A brief introduction highlighting my professional interests and career aspirations.
- 👩‍💻 **About Me** – Information about my academic background, interests, and experience.
- 🛠️ **Technical Skills** – An overview of programming languages, frameworks, libraries, databases, and development tools.
- 💼 **Projects Showcase** – Featured academic and personal projects with descriptions, technologies, and GitHub links.
- 🎓 **Education & Certifications** – Academic qualifications, achievements, and professional certifications.
- 📬 **Contact Section** – Links to connect with me through LinkedIn, GitHub, and other professional platforms.
- 📱 **Responsive Design** – Optimized for desktop, tablet, and mobile devices.

## 🌍 Deployment

The portfolio is deployed using **Vercel**, providing fast and reliable hosting.

The deployment workflow supports automatic updates whenever new changes are pushed to the connected GitHub repository's production branch, provided automatic deployment is enabled.
